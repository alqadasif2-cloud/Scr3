# مواصفات بروتوكول الاتصال الموحد (Smart Remote Protocol Specification v1.1)

تم تصميم هذا البروتوكول ليعمل بكفاءة بين:
1. **برنامج Windows (Smart Remote Control for Windows)**
2. **تطبيق Android (Smart Remote Control for Android)**
3. **وحدة التحكم عبر الويب (Web Remote Client / Signaling Bridge)**

---

## 1. مبادئ الاتصال والشبكة المحلية
- **الاتصال المباشر (Peer-to-Peer / Local LAN):**
  - يتم الاتصال داخل الشبكة المحلية عبر بروتوكول WebSocket الآمن أو TCP Sockets على المنفذ الافتراضي `52840`.
  - لا يتطلب إنشاء حساب في أي سحابة خارجية؛ مما يضمن خصوصية وسرعة فائقة دون تأخير الخوادم الوسيطة.
- **الاكتشاف التلقائي (Local Discovery):**
  - ترسل الأجهزة حزمة UDP Multicast على العنوان `239.255.52.84` والمنفذ `52841` تحتوي على اسم الجهاز ونظام تشغيله ومعرّفه الفريد.
  - بديل الاكتشاف: إدخال رمز اتصال مكون من 6 أرقام (PIN) أو عنوان IP المباشر.

---

## 2. مراحل الاتصال (Handshake Lifecycle)

```
  [الجهاز الطالب (Client)]                     [الجهاز المستضيف (Host)]
          |                                              |
          | ----- 1. HANDSHAKE_HELLO (القدرات) --------> |
          | <---- 2. HANDSHAKE_HELLO_ACK --------------- |
          |                                              |
          | ----- 3. SESSION_REQUEST (الـ PIN) --------> |
          |                                              | (ظهور نافذة الموافقة)
          | <---- 4. SESSION_ACCEPT / REJECT ----------- |
          |                                              |
     [بدء البث]                                     [بدء البث]
          | <==== 5. SCREEN_FRAME_CHUNK (فيديو) ======== |
          | ===== 6. INPUT_EVENT (ماوس / كيبورد) ======> |
          | <---> 7. HEARTBEAT (كل 1000 مللي ثانية) <--> |
          |                                              |
          | ----- 8. DISCONNECT (إيقاف فوري) ----------> |
```

---

## 3. معالجة الإحداثيات الموحدة (Normalized Coordinates)
لتفادي مشاكل اختلاف دقة الشاشات (مثلاً: شاشة كمبيوتر 2560x1440 مقابل شاشة هاتف 1080x2400):
- يتم إرسال الإحداثيات دائماً كقيم قياسية نسبية محصورة بين `0.0` و `1.0`:
  $$X_{normalized} = \frac{X_{client}}{Width_{client}}$$
  $$Y_{normalized} = \frac{Y_{client}}{Height_{client}}$$
- يقوم الجهاز المستهدف بضرب الإحداثيات النسبية في أبعاد شاشته الحقيقية:
  $$X_{target} = X_{normalized} \times Width_{target}$$
  $$Y_{target} = Y_{normalized} \times Height_{target}$$

---

## 4. تدابير الأمان والتشفير
1. **رمز الجلسة المؤقت (6-Digit PIN):** يتغير رمز PIN دورياً، ولا يتم بدء أي جلسة دون موافقة يدوية من المستخدم على الجهاز المستضاف.
2. **التشفير المحلي:** يتم تبادل المفاتيح عبر Diffie-Hellman وتشفير حزم التحكم والفيديو باستخدام خوارزمية AES-256-GCM.
3. **زر الإيقاف الإجباري (Kill Switch):** يمكن لأي من الطرفين إنهاء الجلسة فوراً بلمسة واحدة مما يُسقط مقبس الاتصال ويحرر موارد النظام.
